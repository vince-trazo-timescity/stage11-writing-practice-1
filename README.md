# Stage 11 Writing Practice 1

A lightweight, student-facing Progress Test 1 reviewer for Vinschool Times City. It runs as one static `index.html` file and needs no API key, framework or paid service.

## Learning sequence

Students move through **Plan → Practise → Develop → Draft → Review → Revise → Reflect**. Both genre pathways use the flexible structure **Point → Explanation → Relevant example/evidence → Analysis → Link back** without treating it as a compulsory sentence formula.

### Pathway 1: Biographical article

- Select a central angle and relevant milestones.
- Order an engaging school-magazine article.
- Develop factual details into evidence of character, achievement or influence.
- Correct chronology, reference words, verb forms and spelling.
- Draft, self-review and revise an original article.

### Pathway 2: Opinion essay

- Mine the supplied British Council C1 model for organisation and argument strategy.
- Complete source-based vocabulary, true/false, linking and tentative-language practice.
- Build a focused thesis and a developed body paragraph.
- Practise linker meaning, SVA, verb forms, word order and spelling.
- Draft, self-review and revise an original essay about volunteering.

## Standards mapping

| Standard | Activities | Evidence of learning |
|---|---|---|
| UO 1.g | Biography planning, ordering, development, accuracy and studio | Logical organisation, formal/semi-formal style, developed achievements and evaluation |
| LO 1.5.a | Milestones, timeline choices and tense clinic | Accurate description of what happened, how it happened and what it demonstrates |
| UO 2.h — essay component | Source model, source tasks, thesis, paragraph, cohesion, accuracy and studio | Clear position, developed support, formal register, counterargument and synthesis |

The reviewer does not claim that essay practice alone fulfils UO 2.h's separate webpage component.

## Teacher customisation

Search `index.html` for these visible labels to edit content without changing the interaction code:

- `Stage 11 • Progress Test 1 Writing Reviewer`
- the two writing-studio task headings and prompts
- `Suggested default target: 250–300 words`
- `data-time`, `data-teacher`, `data-check`, `data-support` and `data-transition` notes on each screen

The default timer is 20 minutes. Teachers and students can select 5, 10, 15, 20, 30, 40 minutes or Untimed mode.

## Saving and privacy

Drafts, selected answers, scores, checklists and progress are saved with browser local storage. They remain on the current device and do not synchronise between devices. Copy and Download buttons let students keep their writing elsewhere. Automated writing alerts are suggestions, not grades.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish.

The expected URL is `https://vince-trazo-timescity.github.io/stage11-writing-practice-1/` after Pages is enabled.

## Verification checklist

- 19 responsive screens with no duplicate IDs.
- Adjustable countdown, pause/resume, reset and untimed mode.
- Keyboard slide navigation and keyboard-operable activities.
- Independent reset for each activity and confirmation before destructive clearing.
- Local restoration of drafts, answers, scores and slide position.
- Working copy and text-download controls.
- Long screens scroll vertically instead of shrinking classroom text.
- No external runtime dependencies.
